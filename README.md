# Bookstore Intelligence Mission

## Overview
This project uses Python web scraping to collect and analyze book data from Books to Scrape, a practice website designed for scraping exercises.

## Objectives
- Extract book titles, prices, ratings and availability.
- Scrape multiple catalogue pages using a reusable function.
- Clean and organize data using Pandas.
- Answer business intelligence questions.
- Optimize a £100 research budget using dynamic programming.
- Visualize the distribution of book ratings.

## Technologies
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- NumPy

## How to Run
1. Install the required libraries.
2. Open `bookstore_intelligence_mission.ipynb` in Jupyter Notebook or Google Colab.
3. Run the cells in order.
4. The scraper generates the CSV datasets and the analysis outputs.

## Data Fields
Title, Price, Rating, Availability and Product_URL.

## Results
The notebook reports price statistics, rating counts, availability, a Top 5 book ranking, and the optimized book selection under a £100 budget.

https://books.toscrape.com/
